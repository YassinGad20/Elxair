# Elxair - Online Perfume Store & Analytics 🌸

**Elxair** is a sophisticated .NET MVC web application designed for the fragrance industry. It combines a seamless e-commerce experience with a powerful data-driven administrative dashboard to manage sales and predict future business performance.

---

## 🚀 Key Features

### 🛒 E-Commerce Platform
* **Product Catalog:** A refined browsing experience for luxury perfumes categorized by brand and scent profile.
* **Order Management:** Secure checkout process and real-time order tracking.
* **Responsive Design:** Optimized for a premium experience on both desktop and mobile devices.

### 📊 Admin Dashboard
* **Inventory Control:** Comprehensive CRUD operations for managing perfume sizes, categories, and stock levels.
* **Insightful Analytics:** Modern data visualizations using 'coolwarm' aesthetics to track sales trends.
* **Sales Tracking:** Detailed logs for orders, payments, and customer activity.

### 🧠 Machine Learning Integration
* **Profit Forecasting:** Implements a **Gradient Boosting Regressor** to predict aggregate monthly product profits.
* **Smart Engineering:** Utilizes advanced feature engineering (One-Hot Encoding, Grouping) to provide accurate business insights based on historical sales data.

---

## 🛠️ Tech Stack

* **Backend:** ASP.NET Core MVC, Entity Framework Core
* **Database:** SQL Server
* **Machine Learning:** Python (Scikit-learn, Pandas)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Visualization:** Matplotlib, Seaborn (Custom Modern Styling)
